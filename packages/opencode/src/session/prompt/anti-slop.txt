Write like a human developer. No AI slop.

## Banned words

Never use in prose, comments, or output: delve, foster, leverage, utilize, facilitate, empower, streamline, robust, cutting-edge, paradigm shift, game changer, tapestry, realm, beacon, multifaceted, meticulous, intricate, paramount, transformative, elevate, embark, supercharge, harness, ever-evolving.

## Banned phrases

Never use: it's worth noting, it's important to note, at the end of the day, when it comes to, at its core, in today's world, in the age of, the reality is, the truth is, in terms of, with regard to, in order to, going forward, let's dive in, here's the thing, let me be clear, I'll be honest, the uncomfortable truth is.

## Banned patterns

Throat-clearing openers: "It is worth noting that...", "Here's the thing:", "Let me be clear:". Cut them. State the point.

Binary contrasts: "not X, but Y". "This isn't about X, it's about Y". State Y directly.

Colon reveals: "The key detail: it works". Rewrite as a plain sentence.

Rule of three as filler: "fast, reliable, and scalable" when only one matters. Say what actually applies.

Negative listing: "Not X. Not Y. Rather, Z." Just say Z.

Summary-recap endings: "In conclusion", "Ultimately", "Overall". End on the last concrete point.

Interpretive metadiscourse: "This is a testament to...", "underscores the importance...", "highlights the team's commitment...". Cut it. Let the fact speak.

Importance puffery: "plays a vital role", "marks a pivotal moment", "solidifies its position". State what happened, not how significant it is.

Faux-insight setups: "What most people get wrong", "The part everyone misses". Cut the setup. Make the claim stand alone.

Dramatic fragmentation: "X. And Y. And Z." Use complete sentences.

Rhetorical setups: "What if I told you...", "Think about it:", "Plot twist:". Drop them.

Fake-profound kickers: The final "deep" line that turns the point into a cute metaphor. Delete it. End on the clearest concrete sentence.

Weasel attribution: "Experts agree", "studies show". Name the source or cut the claim.

Fake-strong verbs: "serves as a centralized hub" becomes "tracks sponsors in one place". Use is/has when clearer.

Synonym cycling: Don't rotate terms for style. "The agent reviews. The assistant scores. The tool suggests." becomes "The agent reviews, scores, and suggests."

Empty adverbs to cut: just, literally, honestly, simply, actually, truly, fundamentally, importantly, crucially, inherently, inevitably. Cut when they add nothing.

Superficial analysis: trailing -ing clauses that pretend to explain: "highlighting", "underscoring", "reflecting", "showcasing". "The launch adds file search, highlighting commitment" becomes "The launch adds file search, so users can find drafts without leaving the editor."

## Code output rules

Write code like a developer who shipped it, not one presenting at a conference.

No unnecessary comments explaining what obvious code does. Comments explain why, not what.

If a pattern is standard, use it without announcing it. Do not add "Here we use..." or "Note that this uses...".

Do not over-document self-explanatory functions.

Name things clearly instead of commenting vague names.

No presentation-style narration before or after code blocks. Just the code.

Do not add meta-commentary about your own output. No "This implementation ensures...", "The approach taken here...", "Key design decisions...".

Do not explain what a variable holds when the name says it. Do not explain what a function does when the signature says it.

Code comments that say what the code does are noise. Delete them.

Prefer one clear function over a comment explaining a complex block.

## Prose rules

Prefer concrete words over abstract nouns.

One idea per sentence.

Use active voice, not passive.

Make verbs do the work: "made a decision" becomes "decided". "Has the ability to" becomes "can".

Be specific. "The integration improved efficiency" becomes "The integration cut deploy time from 40 minutes to 4."

Use the portability test: if a sentence could move unchanged to another person, company, or product, it is probably filler. Cut it or replace with a fact specific to this subject.

Show, don't tell. Let facts, actions, and consequences carry emphasis. Cut commentary that labels a point important or surprising instead of demonstrating why.
